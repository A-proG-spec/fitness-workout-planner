# Step-by-Step Guide to Test API Endpoints Using Thunder Client

## Prerequisites

1. **VS Code** installed
2. **Thunder Client** extension installed (search in VS Code extensions)
3. **Backend server** running on `http://localhost:5000`
4. **MongoDB** connected and running

---

## Step 1: Open Thunder Client in VS Code

1. Open VS Code
2. Click on the **Thunder Client** icon in the left sidebar (lightning bolt icon)
3. Alternatively, press `Ctrl + Shift + P` and search for "Thunder Client: New Request"

---

## Step 2: Create Environment Variables

Environments help you store reusable variables like base URL and tokens.

### 2.1 Open Environment Manager
1. Click on the **Environment** dropdown at the top of Thunder Client
2. Select **Manage Environments**
3. Click **New Environment**

### 2.2 Create Development Environment
Name: `Fitness Planner Dev`

Add these variables:

| Variable Name | Initial Value | Current Value |
|--------------|---------------|----------------|
| base_url | http://localhost:5000 | http://localhost:5000 |
| access_token | (leave empty) | (will be filled after login) |
| user_id | (leave empty) | (will be filled after register) |
| plan_id | (leave empty) | (will be filled after creating plan) |
| exercise_id | (leave empty) | (will be filled from exercise list) |

### 2.3 Save Environment
Click **Save** then close the Environment Manager

### 2.4 Select Environment
From the Environment dropdown, select **Fitness Planner Dev**

---

## Step 3: Test Health Check (Warm-up)

### 3.1 Create New Request
Click **New Request** button

### 3.2 Configure Request

| Field | Value |
|-------|-------|
| Method | GET |
| URL | `{{base_url}}/api/health` |

### 3.3 Send Request
Click **Send** button

### 3.4 Expected Response
```json
{
  "success": true,
  "message": "Server is running",
  "timestamp": "2024-...",
  "environment": "development"
}
```

**Status Code:** 200 OK

---

## Step 4: Test User Registration

### 4.1 Create New Request
Click **New Request**

### 4.2 Configure Request

| Field | Value |
|-------|-------|
| Method | POST |
| URL | `{{base_url}}/api/auth/register` |

### 4.3 Set Headers
Click on **Headers** tab and add:

| Header | Value |
|--------|-------|
| Content-Type | application/json |

### 4.4 Set Request Body
Click on **Body** tab, select **JSON** format, and paste:

```json
{
  "name": "Test User",
  "email": "test@example.com",
  "password": "123456",
  "gender": "Male",
  "height": 175,
  "weight": 70,
  "fitnessGoal": "Muscle Gain"
}
```

### 4.5 Send Request
Click **Send** button

### 4.6 Expected Response
```json
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "user": {
      "_id": "65f123456789",
      "name": "Test User",
      "email": "test@example.com"
    },
    "token": "eyJhbGciOiJIUzI1NiIs..."
  }
}
```

### 4.7 Save User ID
Copy the `_id` value from response and add to environment:
1. Click on **Environment** dropdown
2. Select **Manage Environments**
3. Edit **Fitness Planner Dev**
4. Set `user_id` = the copied ID
5. Click **Save**

## Common Issues and Solutions

### Issue 1: Connection Refused
**Solution:** Make sure server is running with `npm run dev`

### Issue 2: 401 Unauthorized
**Solution:** Update `access_token` after login

### Issue 3: 404 Not Found
**Solution:** Check URL and make sure `{{base_url}}` is correct

### Issue 4: Variable Not Replaced
**Solution:** Make sure environment is selected from dropdown

### Issue 5: Invalid Token
**Solution:** Login again to get fresh token
